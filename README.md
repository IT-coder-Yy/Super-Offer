# Super-Offer

面向国内求职者的本地优先开源桌面客户端。

已有多份档案、文字 PDF / DOCX 简历预填与人工确认、版本与复制、自定义问答、七阶段申请和多轮面试、独立聊天 / ASR 配置、任务停止与用量、备份整体恢复。

本分支增加现有 Chrome / Edge 授权连接、表单填写与补空、只读项目导入与证据检索、岗位和项目文字练习／模拟。受控测试与真实网站、模型效果验收分开记录；实现这些入口不表示所有招聘流程已适配。语音复盘、语音输入、题库和自动更新尚未实现。

当前提供源码及本机开发构建，尚未发布安装包。首版目标保留 Windows x64、macOS Intel x64、macOS ARM64、Linux x64 AppImage；Windows 本机验证不代表其它架构已经通过。

## 本地开发

本次验证使用 Node.js 24.14.1、npm 11.11.0、Rust 1.99.1、Windows x64、MSVC 与 WebView2。其它平台需要 Tauri 2 对应的系统依赖。终端用户运行已构建程序不需要 Node 或 Python。

```sh
npm ci
cargo fetch --manifest-path src-tauri/Cargo.toml
npm run desktop
```

`npm run assets` 准备图标、中文 PDF CMap、完整许可和浏览器辅助运行时，输出到 `.s0-work`。首次执行会从固定上游下载 Node.js 24.14.1 和三份补充许可全文，校验 SHA-256 后缓存；缓存和生成资源不进入源码仓库。辅助进程包含 Node 和 Playwright Core，不捆绑浏览器。构建阶段自动调用；离线构建前先联网安装依赖、执行 `cargo fetch` 和 `npm run assets`。许可和运行时默认使用主机目标，交叉构建时将 `SUPER_OFFER_BUILD_TARGET` 设置为与 Tauri `--target` 一致的目标三元组。

```sh
npm test
npm run test:browser
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run desktop:build -- --debug
```

`tests/native-s1.mjs` 是 Windows 原生回归，自动启动自有 WebView、使用独立合成数据目录及本机服务替身。用 `SUPER_OFFER_TEST_EXE` 指定刚构建的程序路径后执行 `node tests/native-s1.mjs`。它不连接用户的 Chrome / Edge，也不调用付费模型。

`tests/native-s23.mjs` 验证新增桌面界面的场次、草稿、报告及恢复流程，使用本机模型替身。浏览器 DOM 回归使用独立测试页面；项目导入、检索、版本引用及迁移失败保全由 Rust 行为测试覆盖。它们均不替代三站完整流程、真实模型效果或其它平台验收。

## 数据与服务

数据保存在系统应用数据目录 `io.superoffer.desktop` 下，可在“数据备份”查看。开发时可用 `SUPER_OFFER_DATA_DIR` 指向独立目录。SQLite 与应用材料副本由宿主管理，同一工作区禁止两个进程同时打开；用户原件不修改。

文字简历上限 10 MB，PDF 上限 100 页，提取文字上限 1 MB；扫描件不提供 OCR。字段建议须人工确认，未知内容保持缺项。ASR 设置页提供 MP3 / WAV / M4A 接口测试，单文件上限 50 MB，尚不代表后续音频识别质量或完整复盘验收。

聊天填写完整 Chat Completions 地址，ASR 填写完整 multipart 转写地址；Key 仅通过系统凭证库保存。运行中的任务固定输入与配置版本，取消保留已收内容；用量未知显示“未知”，不设置客户端调用次数配额。

先在自己的 Edge 或 Chrome 登录招聘网站并打开简历表单。在客户端的“浏览器填写”连接已授权的浏览器，选中这张表单所在的标签页，点击“在此页面打开悬浮窗”。随后直接在网页右上角的悬浮窗里选个人档案。点击“一键填写”会填写能确定的字段并回读结果。点击“补充填写”只填空白，保留官网已有值和手动修改。收起后可在原页面再次打开面板。

配套简历只会传给用途明确的简历上传框。已有简历须先确认替换，作品集、证书和用途不明的附件由本人处理。选择文件后，客户端会核对文件名和该上传框本次的完成提示。

浏览器连接需要当前浏览器支持并允许现有会话调试。换档缺值会保留旧值并标记待核验。填写停在最终提交前，只有用户确认已在网站提交，申请才计为已投。API Key 和完整档案留在本机，网页只接收本次填写需要的信息。

项目目录或 ZIP 只读导入，不执行程序、脚本、依赖安装或 README 指令。默认排除凭证、链接、依赖与构建产物；清单展示排除及失败原因。当前保护值为 20,000 个条目、单文件 2 MiB、总读取 256 MiB、目录深度 64，超出项需要核对，不宣称无限容量。Windows 读取期间持有目录句柄，可能暂时阻止相关目录移动或删除。

本地检索不需要模型。每次外发仅使用已确认范围中的相关片段；可撤回授权。引用保存材料版本、相对路径、行号和内容校验，原目录变化或清理完整副本不会改写已保存证据。秘密识别并非穷尽，外发前仍需核对所选范围。练习按题组反馈，模拟结束后统一反馈；默认 6 个主问题，每题最多 2 次追问，题量可调。源码事实、用户说明和推测分别标记，不把代码存在当作个人贡献或录用概率。

备份格式 v2，兼容 v1 恢复；升级 v1 工作区前先备份，在新数据集迁移成功后才切换。备份仅包含已保存内容，不含 Key 或浏览器登录态；音频和完整项目副本可选，已保存引用和报告始终保留。压缩包最大 256 MB、展开后最大 512 MB；超限需先处理副本范围。恢复先预检、展示范围并确认，再备份当前数据并整体替换，不合并。恢复后重新配置 Key、确认材料外发范围并授权浏览器连接，原数据集及恢复前备份继续保留。

面试可从固定档案版本的配套简历提取文字。在新建场次中核对、删减并勾选同意后，所选聊天服务才会收到这段文字。重新编辑或切换档案需要再次确认。

阅读文字面试报告时，可以逐项对照当时的回答和固定版本的源码。展开“原始模型报告”可查看模型解释、参考回答和薄弱点。发现解释与源码不符时，选择该报告已引用的材料即可在本地保存更正。更正可随备份恢复，历史回答和原报告都可回看。
